# IronClad Banking System - JavaScript Assignment

This project contains 5 JavaScript files demonstrating array methods, loops, conditions, and basic programming concepts through a fictional banking system.

## Files

- **question1.js** - Smart ATM & Transaction History (Array Mutation Methods)
- **question2.js** - Processing Loan Applications (Iterating Methods)
- **question3.js** - Fraud Detection & Ledger Auditing (Accessor & Search Methods)
- **question4.js** - Bank Mergers & Data Cleanup (Formatting & Structuring Methods)
- **question5.js** - Security & Reporting System (Strings & Logic)

## How to Run

### Option 1: Run individual files with Node.js

```bash
node question1.js
node question2.js
node question3.js
node question4.js
node question5.js
```

### Option 2: Run all files at once

```bash
node question1.js && node question2.js && node question3.js && node question4.js && node question5.js
```

### Option 3: Run in browser console

Copy and paste the content of any file into your browser's developer console (F12).

## What Each File Demonstrates

### Question 1: Smart ATM & Transaction History
- **Array Methods**: `push()`, `pop()`, `shift()`, `unshift()`
- **Concepts**: Balance management, transaction validation, history tracking
- **Features**: Withdrawal, Deposit, Undo, Fee processing

### Question 2: Processing Loan Applications
- **Array Methods**: `filter()`, `map()`, `reduce()`, `some()`, `every()`, `find()`, `findIndex()`
- **Concepts**: Credit score evaluation, batch processing
- **Features**: Eligibility filtering, score adjustment, risk calculation

### Question 3: Fraud Detection & Ledger Auditing
- **Array Methods**: `includes()`, `indexOf()`, `slice()`, `splice()`, `forEach()`
- **Concepts**: Transaction auditing, fraud detection
- **Features**: Fraud ID checking, transaction removal, safe transaction clearing

### Question 4: Bank Mergers & Data Cleanup
- **Array Methods**: `concat()`, `flat()`, `sort()`, `reverse()`, `join()`, `fill()`
- **Concepts**: Database merging, data formatting
- **Features**: Branch merging, data flattening, customer sorting, teller initialization

### Question 5: Security & Reporting System
- **String Methods & Logic**: `length`, `toLowerCase()`, `includes()`, loops, conditionals
- **Concepts**: Password validation, leap year calculation, anniversary tracking
- **Features**: Password security rules, yearly reports with milestones
